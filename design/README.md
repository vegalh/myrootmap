# design/

Working material for the website. Nothing in this folder is published.

| Folder | What is in it |
|---|---|
| `sketches/` | Hand-drawn layouts. `homepage-sketch.png` is the first sketch of the homepage. |
| `photo-originals/` | Full-size originals of photographs used on the site. Each is named after the web copy it was made from, which lives in `public/images/` (for example `home-hero-cooking-together.png` → `public/images/home/hero-cooking-together.jpg`). Keep these for re-cropping or re-exporting. |
| `screenshots/` | Full-page screenshots of the homepage, one folder per date, in English and Chinese at phone (390 px) and desktop (1440 px) width. |

## screenshots/

| Folder | Shows |
|---|---|
| `2026-11-12-old-homepage/` | The homepage before the restructure (nine sections, about 15 phone screens). |
| `2026-11-13-new-homepage/` | The homepage after the restructure (five sections and the invite form). The invite form is empty in these, because its link had not been added yet. |

Name new folders `YYYY-MM-DD-what-changed/` so they sort by date.
